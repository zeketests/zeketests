## 🚀 Featured Projects

### 🔍 [rag-eval-project](https://github.com/zeketests/rag-eval-project): Testing a RAG system like a QA engineer
A local Retrieval-Augmented Generation app over 151 Pokémon, plus an **evaluation framework** to test it. It uses a golden dataset of 50 cases, retrieval hit-rate metrics, an **LLM-as-judge** grader, rule-based checks for refusals, and error analysis.
**Result:** 98% answer correctness. It refused all "memory trap" questions instead of hallucinating, and the one failure was traced to reasoning, not retrieval.
`Python` `Ollama` `sentence-transformers` `pytest`

### 🎭 [saucedemo-playwright-claude](https://github.com/zeketests/saucedemo-playwright-claude): AI-assisted E2E framework
A full test automation framework built with **Claude Code**: **91 tests** (74 browser + 17 API), Page Object Model, `@smoke`/`@regression` tags, known defects tracked with `test.fail()`, Docker runs, and Allure reports published to GitHub Pages from CI.
`Playwright` `TypeScript` `Docker` `GitHub Actions` `Allure`

### 🤖 [ai-gen-framework](https://github.com/zeketests/ai-gen-framework): A test framework designed for AI agents to maintain
A Playwright framework built so that **AI coding agents write, extend and maintain the tests**, with a custom `/pr` skill for agent-driven test generation and pull requests. It includes **axe-core accessibility scans** (WCAG 2 A/AA) and a lint-gated CI pipeline.
`Playwright` `TypeScript` `Claude Code` `axe-core` `GitHub Actions`

### 🧠 [playwright-engineer](https://github.com/zeketests/playwright-engineer): A Claude Code Skill
A **Claude Skill** that turns Claude into a Senior QA Automation Engineer. It enforces POM, typed fixtures, semantic locators, auth patterns, API mocking and CI best practices, and loads its reference guides on demand to save tokens.
`Claude Code` `Agent Skills` `Playwright`
